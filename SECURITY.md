# Security reporting

This project is a development candidate. Do not post credentials, real workout data or private platform details in issues or pull requests. Use private vulnerability reporting when enabled, or contact the repository owner privately.

Public CI uses ephemeral hosted runners, no staging/production credentials and read-only repository permissions. Pull requests must not run on a production-connected self-hosted runner or execute with privileged tokens. Synthetic native account fixtures are local-only and never published or uploaded as artifacts.
